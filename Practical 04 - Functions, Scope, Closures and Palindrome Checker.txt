Practical 4: Functions, Scope, Closures and Palindrome Checker
Aim: To demonstrate function types, scope, closures and exception handling using a palindrome checker.

Theory: Functions are reusable blocks of code. JavaScript supports function declarations, function expressions and arrow functions. A closure retains access to its enclosing scope. try...catch handles thrown errors.

Code — index.html:
<!DOCTYPE html>
<html>
<body>
<input id="word" placeholder="Enter word">
<button onclick="check()">Check</button>
<p id="result"></p>

<script>
// Function declaration
function check() {
  try {
    let s = document.getElementById("word").value.toLowerCase();
    if (!s) throw "Enter a word";

    let rev = s.split("").reverse().join("");
    document.getElementById("result").innerHTML =
      s === rev ? "Palindrome" : "Not Palindrome";
  }
  catch(e) {
    document.getElementById("result").innerHTML = e;
  }
}

// Function expression
let add = function(a,b) { return a+b; };

// Arrow function
let square = n => n*n;

// Closure
function counter() {
  let count = 0;
  return () => ++count;
}
let c = counter();
console.log(c(), c());
</script>
</body>
</html>

Conclusion: Function types, scope, closures and error handling were demonstrated through palindrome checking.

How to run:
1. Create a folder named Practical_04.
2. Save the code as index.html and open it.
3. Enter madam and click Check.
4. Enter hello to test a non-palindrome.
5. Leave the input empty to test error handling.
6. Repeat checks to observe the counter maintained by the closure.
