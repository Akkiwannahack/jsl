Practical 7: DOM Traversal and To-Do List
Aim: To perform DOM traversal and updates using a to-do list with add, edit and delete features.

Theory: The Document Object Model represents HTML as a tree of elements. JavaScript can create, access, modify and remove these elements. Methods such as closest() and querySelector() navigate the DOM.

Code — index.html:
<!DOCTYPE html>
<html>
<head><title>To-Do List</title></head>
<body>
  <h2>To-Do List</h2>
  <input id="task" placeholder="Enter task">
  <button id="add">Add</button>
  <ul id="list"></ul>

  <script>
    const input = document.getElementById("task");
    const list = document.getElementById("list");

    document.getElementById("add").onclick = function () {
      if (!input.value.trim()) return;

      const item = document.createElement("li");
      const text = document.createElement("span");
      text.textContent = input.value.trim();
      item.appendChild(text);

      for (const action of ["Edit", "Delete"]) {
        const button = document.createElement("button");
        button.textContent = action;
        item.appendChild(button);
      }

      list.appendChild(item);
      input.value = "";
    };

    list.onclick = function (event) {
      if (event.target.tagName !== "BUTTON") return;

      const item = event.target.closest("li");
      const text = item.querySelector("span");

      if (event.target.textContent === "Delete") {
        item.remove();
      } else {
        const updated = prompt("Edit task:", text.textContent);
        if (updated && updated.trim()) text.textContent = updated.trim();
      }
    };
  </script>
</body>
</html>

Conclusion: DOM creation, traversal, modification and removal were demonstrated using a to-do list.

How to run:
1. Create a folder named Practical_07.
2. Save the code as index.html and open it.
3. Enter a task and click Add.
4. Click Edit to change a task.
5. Click Delete to remove a task.
