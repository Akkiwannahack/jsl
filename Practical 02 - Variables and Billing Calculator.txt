Practical 2: Variables and Billing Calculator
Aim: To use var, let, const, template literals and destructuring in a billing calculator.

Theory: var declares function-scoped variables, while let and const are block-scoped. A const binding cannot be reassigned. Template literals insert values into strings, and destructuring extracts values from arrays or objects.

Code — index.html:
<!DOCTYPE html>
<html>
<head><title>Billing Calculator</title></head>
<body>
  <h2>Billing Calculator</h2>

  <form id="bill">
    <input id="price" type="number" min="0" step="0.01"
           placeholder="Price" required>
    <input id="quantity" type="number" min="1" step="1"
           placeholder="Quantity" required>
    <button>Calculate</button>
  </form>

  <p id="result"></p>

  <script>
    var shop = "Student Store";
    const taxRate = 0.05;

    document.getElementById("bill").onsubmit = function (event) {
      event.preventDefault();

      const item = {
        price: Number(document.getElementById("price").value),
        quantity: Number(document.getElementById("quantity").value)
      };

      const { price, quantity } = item;
      let subtotal = price * quantity;
      let total = subtotal * (1 + taxRate);

      document.getElementById("result").textContent =
        `${shop}: Subtotal ₹${subtotal.toFixed(2)}, ` +
        `Total with 5% tax ₹${total.toFixed(2)}`;
    };
  </script>
</body>
</html>

Conclusion: JavaScript variables, destructuring and template literals were used to calculate a bill.

How to run:
1. Create a folder named Practical_02.
2. Save the code as index.html.
3. Open the file in a browser.
4. Enter price and quantity, then click Calculate.
5. For price 100 and quantity 2, the total should be ₹210.00.
